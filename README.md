# Novarix 交易所原型

一个高保真、可交互的中心化交易所原型（纯前端，数据为模拟），包含：

| 模块 | 功能 |
| --- | --- |
| 首页（新增） | 默认落地页：主视觉与实时行情面板、平台数据、热门活动入口、市场行情（热门 / 涨幅榜 / 跌幅榜 / 新币）、全部产品入口、三步开始引导 |
| 活动中心（新增） | ① ORIA 申购（已申购 278,500 / 500,000 名额）：确认申购信息 → 唤起钱包签名（可拒绝 / 重新签名）→ 签名验证 → 申购成功凭证；申购结束后 1 小时公布分配结果，领取时确认接收地址与网络，空投到用户的交易所地址，显示链上发放、区块确认与到账回执；另有「我的申购」详情页（时间线 + 申购凭证 + 签名内容）。其余 4 个活动奖励为 USDT，单个钱包全部完成共 18 USDT：② 邀请好友（每位好友 1 USDT，最多计 5 位，满 3 / 5 位各加 1 USDT，共 7）；③ 每日签到（累计 7 天，共 4 USDT）；④ 关注社媒（5 个任务 3 USDT + 全部完成奖励 1 USDT）；⑤ 答题（全对 3 USDT）。所有领取都空投到交易所地址并计入现货账户，资金记录可点开查看到账回执 |
| 钱包连接 | 选择插件钱包 → 授权连接 → 签名登录（SIWE 样式），账户面板显示链上余额、切换网络、领取测试币、断开连接 |
| 充提 | 平台为每个网络分配专属充值地址（含二维码）；可从已连接钱包直接转入或模拟外部到账，实时显示区块确认进度；提币含网络手续费、安全验证码与链上进度；现货 ↔ 合约划转；闪兑（报价 8 秒有效） |
| 认购 Launchpad | 进行中 / 即将开始 / 已完成三类项目，倒计时、募集进度、超募倍数；项目详情页含愿景、亮点、代币经济饼图、释放曲线、路线图、团队与投资方、认购规则；按 NVX 质押等级放大认购上限；超募按比例分配并自动退款，TGE 解锁 + 线性释放，可领取 |
| 现货 | 交易对选择（搜索 / 自选 / USDT、USDC 区），K 线（1m–1d、MA7/MA25、成交量），订单簿（点击价格带入）、实时成交，限价 / 市价 / 闪兑下单，当前委托 / 历史委托 / 成交记录 / 资产 |
| 合约 | USDT 永续，全仓 / 逐仓、1–125x 杠杆、限价 / 市价、止盈止损，仓位实时盈亏、ROE、强平价，追加保证金、部分 / 全部平仓，资金费率倒计时，强平模拟 |
| Swap | 用现货账户余额直接兑换：自动路由（非稳定币经 USDT 中转）、价格影响、最少收到、滑点设置（0.1% / 0.5% / 1% / 自定义）、15 秒报价倒计时与超滑点自动取消、交易对 24h 走势、可兑换资产与兑换记录 |
| 质押（新增） | 活期 / 定期产品，收益按秒累计，领取、到期赎回、提前赎回扣罚；NVX 质押等级（青铜→钻石）提升认购上限与手续费折扣 |
| 借贷（新增） | 存款 / 取出 / 借款 / 还款，利用率驱动的拐点利率模型，抵押品开关，健康度仪表盘与借款额度，健康度 < 1 自动清算 |

| 钱包 | 账户净值（总览 / 现货 / 合约 / 质押 / 借贷）、资产分布图、插件钱包链上资产、完整资产列表（隐藏零余额）、资金记录 |

其他：八种语言（默认繁體中文，另有简体中文、日本語、English、한국어、Bahasa Melayu、Español、Filipino；访客手动选择后会记住）、深浅色主题、手机端适配、左下角“演示”控制台（一键入金、时间快进、行情冲击测试强平、重置数据）。所有状态保存在浏览器本地。

## 运行

```bash
npm install
npm run dev            # 本地开发
npm run build          # 生成 build/index.html（单文件，React / K 线库 / 二维码库走 CDN），构建产物随仓库提交
npm run build:artifact # 额外生成 artifact/prepdex.html 用于发布
node scripts/build-i18n.mjs  # 生成多语言字典与简体中文对照表，并列出尚未翻译的文案（npm run build 会自动执行）
```

新增或修改文案时，调用处写 `L('繁體中文', 'English')`；简体中文在构建时由繁体自动转换生成（`src/core/i18n-hans.js`，含大陆用词替换）；其他语言按英文原文在 `i18n/translations.json` 中查找（列顺序：ko、ja、ms、es、fil），含变量的文案用 `{0}`、`{1}` 占位。

所有项目、商家与数据均为虚构，仅用于演示。
